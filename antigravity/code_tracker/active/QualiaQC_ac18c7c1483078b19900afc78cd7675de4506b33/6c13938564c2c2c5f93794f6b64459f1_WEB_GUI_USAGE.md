ì# QualiaQC - Web GUI Usage Guide

This document provides a walkthrough of the new Web-based interface for QualiaQC.

## Launching the Web Application

The Web GUI is typically deployed via Docker.
```bash
docker-compose up --build
```
Once running, access the application at `http://localhost:3000` (or the configured port).

---

## Main Sections

The application is divided into four main attributes:

1.  **Analysis**: The engine for running new QC checks. Select a project, upload your test sample and color checker, and run the pipeline.
2.  **History**: View and search past analysis sessions.
3.  **Projects**: Create and switch between projects.
4.  **Dataset**: Manage project files and configuration.

---

## Analysis Engine

The **Analysis** tab allows you to run the full inspection pipeline on a new sample.

### Features
-   **Part & Project Selection**: Choose your active project.
-   **File Uploads**: Upload the main sample image and optionally a project-specific color checker.
-   **Advanced Config**: Toggle individual pipeline steps (Color Alignment, Geometric Alignment, Object Alignment, Masking, etc.) directly from the GUI.
-   **Real-time Logic**: The backend processes the image and provides instant visual feedback.
-   **Download PDF**: Once complete, a **"DOWNLOAD PDF REPORT"** button appears, allowing you to save the official report locally.

---

## History & Reports

The **History** tab maintains a database of all previous analysis runs.

### Features
-   **Search & Filter**: Find sessions by ID, project name, or date.
-   **Download**: One-click download for the generated PDF report of any past session.
-   **Regenerate**: For legacy `.gri` files or existing sessions, you can trigger a "Regenerate" request to recreate the report with current settings.

---

## Dataset Management (File Placer)

The **Dataset** tab allows you to configure the project's reference assets. This fully replaces the legacy "File Placer" tool.

### Features

#### 1. Configuration Files
You can upload or check the status of critical configuration files:
-   **Ideal Reference Color Checker**: The high-quality scan of the color chart.
    -   *Validation*: The system automatically attempts to detect color patches in your uploaded image.
    -   *Status*: Displays "FOUND" (Green) or "MISSING" (Red). If valid, it also shows the number of patches detected (e.g., "Found 140 patches").
-   **Project-Specific Color Checker**: A photo of the color chart taken in the same lighting as your sample.
-   **ArUco Reference**: Verification image for geometric alignment.
-   **Object Reference**: Reference image for object alignment.
-   **Drawing Layers**: Overlay masks (e.g., `layer1`, `layer2`).

**To Upload:** Click the **Upload Icon** next to any file slot and select your file.

#### 2. Calibration Images
Manage the dataset used for defining the target color standards.

-   **Add Images**: Click the **"ADD IMAGES"** button to upload one or more calibration images (PNG/JPG) at once.
-   **Delete**: Hover over any image thumbnail and click the **Trash Icon** to remove it from the dataset.
-   **Preview**: All images are displayed in a grid for easy review.

---

## Projects

The **Projects** tab allows you to:
-   View a list of all available projects.
-   Select the active project for analysis.
-   Create new projects (scaffolds the directory structure).
