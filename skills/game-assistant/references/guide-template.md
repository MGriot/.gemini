## GUIDE QUALITY CHECKLIST

Before finalizing a guide, verify:
- [ ] Quick Start is ≤ 200 words and fully standalone
- [ ] Turn flowchart is present and unambiguous
- [ ] Every rule in Core Rules has source (rulebook page or official URL)
- [ ] All game-specific terms are in Glossary
- [ ] Common Mistakes table has at least 5 entries
- [ ] Strategy section covers all three tiers
- [ ] Resources section has at minimum: rulebook link + BGG page
